# Financial Report Management System

## Description

Our project aims to use a mobile application to fix the problem of our client, Ibrahim Shalaby. Ibrahim is a restaurant owner who currently writes his daily financial reports on paper and then manually transfers the information to an Excel sheet. This process is very time-consuming and can often lead to calculation and data entry errors. Ibrahim has basic computer skills and is comfortable using Office 365, but he does not have programming knowledge and needs a simple mobile application. To solve this problem, our team developed an easy-to-use mobike application that will allow him to automatically process the data and calculations. The system will improve accuracy and save time, while still having room for personal changes if corrections are needed.
